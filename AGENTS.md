# ABS Massage project instructions

## Completing repository tasks

The project owner has given standing authorization to push completed task changes
to `https://github.com/MoltenDevStudio/absmassage` and open a regular pull request.

- After implementing and checking a task, commit its changes on a task branch,
  push the branch to `origin`, and open a pull request targeting `main`.
- Open the pull request ready for review (`draft: false`). Do not default to a
  draft pull request or stop at a local commit, patch, or proposed PR description.
- If the task already has an open pull request, push follow-up changes to its
  branch and update its title and description instead of creating a duplicate.
- Do not ask for routine confirmation to push or open the pull request. These
  actions are part of the owner's requested workflow for this project.
- Include relevant validation results and material limitations in the PR
  description, and provide the verified PR URL in the final response.
- If an actual permission, authentication, or policy block prevents publishing,
  report the specific failure. Do not claim that a pull request was opened.
- Opening a pull request does not authorize merging it.
